# KOSPI 코스터 🎢

코스피 그래프가 그대로 롤러코스터 레일이 되는 웹 게임입니다. 장중에는 1시간마다 새 레일이 깔립니다.

## 레일 규칙

- **레일 끝** = 가장 최근 지수 (장중이면 "지금", 장 마감 뒤면 그날 종가)
- **1일** = 끝 시점에서 전 거래일의 같은 시각부터
  - 장중 11:00 → 전 거래일 11:00 ~ 오늘 11:00 (정확히 24시간)
  - 장 마감 뒤 ~ 다음 장 시작 전 → 전 거래일 종가 ~ 마지막 거래일 장 마감
  - 밤·주말·휴일은 지수가 없어서 레일에서는 짧은 🌙 터널로 지나갑니다 (밤사이 갭도 표시)
- 기간은 6가지입니다.

  | 기간 | 시작 | 데이터 | 땅 눈금 |
  |---|---|---|---|
  | 1일 | 전 거래일 같은 시각 | 1분봉 | 매시 |
  | 1주 | 달력 기준 7일 전 같은 시각 | 1분봉 | 매시 |
  | 3달 | 3달 전 같은 날짜·시각 | 1시간봉 | 매일 |
  | 1년 | 1년 전 같은 날짜 | 일봉 | 매달 |
  | 5년 | 5년 전 같은 날짜 (로그 눈금) | 일봉 | 매달 |
  | 전체 | 1996년 12월부터 (로그 눈금) | 주봉 | 매년 |

- 오르막은 빨강, 내리막은 파랑 (한국 증시 색)
- 평범한 날도 재미있도록 레일 높이는 그 기간의 최저~최고에 맞춰 늘립니다. 실제 변동폭은 스릴 ★로 보여 줍니다.
- **모든 탑승은 30초 안에 끝납니다.** 레일을 만들 때 미리 한 번 달려 보고, 30초가 넘으면 그 레일의 오르막 속도를 올립니다
  (기본 오르막 속도 약 54km/h). 데이터가 매시간 바뀌어도 항상 지켜집니다.
- 5년·전체는 지수가 몇 배씩 움직여서 로그 눈금을 씁니다. 같은 % 움직임이 같은 높이가 되어, 옛날 폭락·급등도 잘 보입니다.

## 조작

화면이나 🙌 버튼을 **누르고 있는 동안 만세**(PC는 스페이스바).
빠르고 아찔한 구간일수록 점수가 커지지만 멀미도 쌓이고, 멀미 100%면 기절합니다.

## 데이터

- 출처: 야후 파이낸스 `^KS11` (API 키 필요 없음, 약 15~20분 지연)
  - 1분봉(최근 8일), 1시간봉(약 110일), 일봉(약 5년), 주봉(1996년 12월~, 야후에 있는 가장 오래된 자료)
  - 시간봉·일봉·주봉의 끝은 1분봉의 최신 값에 맞춰서, 모든 기간이 "지금"에서 끝납니다.
- 야후 분봉은 14:59까지만 있어서, 장이 끝난 날은 일봉 종가를 15:30 지점에 붙입니다.
- 지수는 KRX 정규장(09:00~15:30)에만 계산되므로 그 밖의 시간은 데이터가 없습니다.
- 비공식 데이터라 언제든 바뀌거나 끊길 수 있습니다. 실패하면 직전 레일이 그대로 유지됩니다.

## 갱신 방식

`.github/workflows/deploy.yml`이 평일 장중 매시 25분(한국 시간 09:25~16:25, 18:25)에
데이터를 받아 GitHub Pages로 다시 배포합니다.
야후 데이터가 15~20분 늦게 들어오므로, 25분에 받으면 그 시각 정각 무렵까지의 레일이 깔립니다.
열려 있는 게임 화면은 5분마다 새 레일이 있는지 확인하고, 탑승 중이면 다음 탑승부터 적용합니다.

- GitHub의 예약 실행은 붐빌 때 몇 분~수십 분 늦을 수 있습니다.
- 공개 저장소에서 60일 동안 커밋이 없으면 GitHub이 예약 실행을 멈춥니다. Actions 탭에서 다시 켜면 됩니다.

### 처음 한 번 설정

1. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿉니다.
2. **Actions** 탭에서 "레일 갱신 & 배포"를 한 번 실행(Run workflow)합니다.
3. 주소: `https://<사용자명>.github.io/<저장소명>/`

## 로컬 실행

```bash
npm run fetch   # 최신 데이터 받기 → site/data/kospi.json
npm run dev     # http://localhost:5173
npm test        # 기간 규칙 + 30초 제한 테스트
```

의존성 설치가 필요 없습니다 (Node 20 이상).

## 구조

```
site/
  index.html, style.css
  src/window.js   탑승 기간 계산 (1일·1주·3달·1년·5년·전체)
  src/track.js    지수 → 레일 모양 + 물리
  src/main.js     그리기, 조작, 점수, 자동 갱신
  data/kospi.json 지수 데이터 (Actions가 매시간 덮어씀)
scripts/fetch-kospi.mjs  데이터 수집
scripts/serve.mjs        로컬 서버
test/window.test.mjs   기간 규칙 테스트
test/track.test.mjs    30초 안에 끝나는지 테스트 (기간별 최악의 레일)
```
