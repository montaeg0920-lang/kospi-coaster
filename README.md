# KOSPI 코스터 🎢

코스피 그래프가 그대로 롤러코스터 레일이 되는 웹 게임입니다. 장중에는 1시간마다 새 레일이 깔립니다.

## 레일 규칙

- **레일 끝** = 가장 최근 지수 (장중이면 "지금", 장 마감 뒤면 그날 종가)
- **1일** = 끝 시점에서 전 거래일의 같은 시각부터
  - 장중 11:00 → 전 거래일 11:00 ~ 오늘 11:00 (정확히 24시간)
  - 장 마감 뒤 ~ 다음 장 시작 전 → 전 거래일 종가 ~ 마지막 거래일 장 마감
  - 밤·주말·휴일은 지수가 없어서 레일에서는 짧은 🌙 터널로 지나갑니다 (밤사이 갭도 표시)
- 기간은 6가지입니다.

  | 기간 | 시작 | 데이터 | 땅 눈금 |
  |---|---|---|---|
  | 1일 | 전 거래일 같은 시각 | 1분봉 | 매시 |
  | 1주 | 달력 기준 7일 전 같은 시각 | 1분봉 | 매시 |
  | 3달 | 3달 전 같은 날짜·시각 | 1시간봉 | 매일 |
  | 1년 | 1년 전 같은 날짜 | 일봉 | 매달 |
  | 5년 | 5년 전 같은 날짜 | 일봉 | 매달 |
  | 전체 | 1996년 12월부터 | 주봉 | 매년 |

- 오르막은 빨강, 내리막은 파랑 (한국 증시 색)
- 평범한 날도 재미있도록 레일 높이는 그 기간의 최저~최고에 맞춰 늘립니다. 실제 변동폭은 스릴 ★로 보여 줍니다.
- **일반 코스 탑승은 30초 안에 끝납니다.** 레일을 만들 때 미리 한 번 달려 보고, 30초가 넘으면 그 레일의 오르막 속도를 올립니다
  (기본 오르막 속도 약 54km/h). 데이터가 매시간 바뀌어도 항상 지켜집니다.
- 모든 기간은 일반(선형) 눈금을 씁니다. 같은 포인트 변화가 같은 높이 차이로 표시됩니다.

- 낮·밤 전환은 1일·1주 코스에만 적용합니다. 3달·1년·5년·전체 코스는 시간에 따른 밤 전환 없이 등락에 따라 날씨가 바뀝니다.

## 조작

- 화면이나 🙌 버튼을 **누르고 있는 동안 만세**(PC는 스페이스바). 손을 들고 있을 때만 점수가 쌓이고, 빠르고 아찔할수록·오래 들수록(콤보 최대 ×3) 많이 쌓입니다.
- **멀미**: 내리막을 내려가기만 해도 쌓이고(가파르고 빠를수록 많이), 손을 들면 더 쌓입니다(내리막에서 들면 더 크게).
  오르막·평지에서 손을 내리고 있으면 가라앉습니다. 100%면 기절하고 점수가 멈춥니다.
- **위 그래프로 이동**: 탑승 중 위쪽 그래프의 기차를 끌거나 원하는 곳을 누르면 그 위치로 이동합니다.
  구간을 건너뛴 탑승은 최고 기록에 넣지 않습니다.
- **배속**: ×1 · ×1.5 · ×2 · ×4 (고른 값은 기억합니다)
- **탑승 중 기간 바꾸기**: 그래프 아래 기간 버튼을 누르면 그 기간으로 바로 다시 출발합니다. 오른쪽 **나가기** 버튼(또는 Esc)을 누르면 메뉴로 돌아갑니다.
- **결과**: 기절하지 않고 끝까지 타면 "완주! 🎉", 기절하면 "기절! 😵"입니다.
- **최고 기록**: 실시간 코스는 기간 + 날짜별로 저장합니다(레일이 매시간 길어져도 같은 날 기록은 이어지고, 날이 바뀌면 새로 시작).
  역사 코스는 코스별로 계속 남깁니다. 2주가 지난 날짜의 기록은 지웁니다.
- **소리·진동**: 바람·레일 소리와 출발·만세·기절·도착 효과음, 진동이 있습니다(음원 파일 없이 직접 합성).
  메뉴와 탑승 화면의 🔊 버튼으로 켜고 끄며, 고른 값은 기억합니다. 화면을 벗어나면 소리가 바로 멈추고 돌아오면 다시 납니다.
  아이폰 브라우저는 웹 진동을 지원하지 않아 진동은 안드로이드에서만 동작합니다.
- **타는 법 안내**: 첫 탑승 전에 한 번 보여 주고, 메뉴의 "❔ 타는 법"에서 다시 볼 수 있습니다.
- **결과 공유**: 결과 카드 이미지를 만들어 공유합니다. 이미지 공유가 안 되는 기기에서는 글만 공유하거나 복사합니다.

이 게임은 실제 코스피 지수로 만든 오락용 게임이며, 투자 권유나 조언이 아닙니다.

## 데이터

- 출처: 야후 파이낸스 `^KS11` (API 키 필요 없음, 약 15~20분 지연)
  - 1분봉(최근 8일), 1시간봉(약 110일), 일봉(약 5년), 주봉(1996년 12월~, 야후에 있는 가장 오래된 자료)
  - 시간봉·일봉·주봉의 끝은 1분봉의 최신 값에 맞춰서, 모든 기간이 "지금"에서 끝납니다.
- 야후 분봉은 14:59까지만 있어서, 장이 끝난 날은 일봉 종가를 15:30 지점에 붙입니다.
- 지수는 KRX 정규장(09:00~15:30)에만 계산되므로 그 밖의 시간은 데이터가 없습니다.
- 비공식 데이터라 언제든 바뀌거나 끊길 수 있습니다. 실패하면 직전 레일이 그대로 유지됩니다.

## 갱신 방식

`.github/workflows/deploy.yml`이 평일 장중 매시 25분(한국 시간 09:25~16:25, 18:25)에
데이터를 받아 GitHub Pages로 다시 배포합니다.
야후 데이터가 15~20분 늦게 들어오므로, 25분에 받으면 그 시각 정각 무렵까지의 레일이 깔립니다.
열려 있는 게임 화면은 5분마다 새 레일이 있는지 확인하고, 탑승 중이면 다음 탑승부터 적용합니다.

- GitHub의 예약 실행은 붐빌 때 몇 분~수십 분 늦을 수 있습니다.
- 공개 저장소에서 60일 동안 변화가 없으면 GitHub이 예약 실행을 멈춥니다. 이를 막으려고 예약 실행 때마다 워크플로를
  '켜짐'으로 다시 표시합니다. 그래도 멈췄다면 Actions 탭에서 다시 켜면 됩니다.
- 배포가 GitHub 쪽 일시 오류로 실패하면 30초 뒤 한 번 더 시도합니다.

### 처음 한 번 설정

1. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿉니다.
2. **Actions** 탭에서 "레일 갱신 & 배포"를 한 번 실행(Run workflow)합니다.
3. 주소: `https://<사용자명>.github.io/<저장소명>/`

## 로컬 실행

```bash
npm run fetch   # 최신 데이터 받기 → site/data/kospi.json
npm run dev     # http://localhost:5173
npm test        # 기간 규칙 + 30초 제한 + 점수·멀미 규칙 테스트
```

의존성 설치가 필요 없습니다 (Node 20 이상).

## 역사적 대상승·대폭락 체험

메인 메뉴의 **코스피 대상승 대폭락 롤러코스터 타기**에서 7개 코스를 선택합니다.
기존 레일 렌더링, 만세 조작, 멀미, 점수, 최고 기록, 결과 공유를 그대로 사용합니다.
모두 일반 눈금을 사용하며 시간에 따른 밤 전환 없이 등락에 따라 날씨가 바뀝니다. 최고 기록은 일반 코스와 구분해 저장합니다.

| 코스 | 실제 종가 구간 | 최대 탑승 시간 |
|---|---|---|
| IMF | 1997-07-01 ~ 1998-06-16 | 45초 |
| 위기 뒤의 대반등 | 1998-06-16 ~ 1999-12-28 | 45초 |
| 닷컴 버블 | 2000-01-04 ~ 2000-12-26 | 45초 |
| 금융위기 | 2008-07-01 ~ 2009-06-30 | 60초 |
| 코로나 충격 | 2020-02-03 ~ 2020-03-19 | 30초 |
| 코로나 이후 상승 | 2020-03-19 ~ 2021-06-25 | 45초 |
| 2025 역사적 대상승 | 2024-12-30 ~ 2025-12-30 | 45초 |

데이터: 네이버 금융 KOSPI 일별 종가. `site/data/history.json`에 필요한 구간만 보관하며
원본 조회 주소도 함께 기록했습니다. 이 파일은 정기 실시간 데이터 갱신으로 덮어쓰지 않습니다.
2025년은 전년도 마지막 종가를 포함하므로 연간 +75.63%와 구간 수익률이 일치합니다.
구간 등락률은 처음과 마지막 종가의 변화, 최대 낙폭은 구간 내 앞선 최고 종가 대비 최대 하락률입니다.
과거 일봉 사이의 레일은 보간되므로 당시 장중 경로를 재현한 것은 아닙니다.

## 상승·하락 날씨 연출

레일의 현재 기울기에 따라 하락 시 먹구름·비·안개, 상승 시 햇빛·따뜻한 하늘·금빛 입자를 표시합니다.
최근 진행 구간의 실제 종가 변화율과 코스 전체 변동폭으로 효과의 강도를 조절합니다.
효과는 부드럽게 전환되며, 1일·1주의 기존 밤 터널은 유지됩니다. 장기 코스의 어두운 하늘은 하락 날씨입니다.
운영체제의 동작 줄이기 설정에서는 비와 입자의 움직임·광선을 줄입니다. 주행 물리와 점수 규칙은 동일합니다.

## 캐릭터

첫 화면에서 6종(노란 후드, 초록 재킷, 시바견, 곰, 로봇, 우주비행사) 가운데 하나를 고르면, 그 캐릭터 세 명이
열차 세 칸에 한 명씩 탑니다. 만세를 하면 세 명 모두 손을 번쩍 든 그림으로 바뀌어 폴짝폴짝 뛰고, 기절하면 뒤로 넘어갑니다.
그림은 `site/characters/*.png`, 목록은 `site/src/characters.js`에 있습니다.
만세 그림(`*-cheer.png`)은 만세 캐릭터 시트에서 잘라 앉은 그림과 크기를 맞춥니다: `python3 scripts/prepare-cheer.py <시트.png>` (Pillow 필요).

## 토스 인앱 (앱인토스)

게임 코드는 웹과 같고, 토스 안에서만 필요한 기능은 `toss/bridge.js`가 토스 SDK(`@apps-in-toss/web-framework` 3.x)로 연결합니다.
게임은 `site/src/platform.js`를 통해서만 그 기능을 쓰므로, 웹에서는 아무 영향이 없습니다.

```bash
npm install          # 토스 SDK와 esbuild 설치 (웹 배포와 테스트에는 필요 없음)
npm run toss:build   # dist-toss 폴더를 만들고 kospi-coaster.ait 로 포장
npm run toss:deploy  # 앱인토스에 업로드 (먼저 npx ait token add 로 키 등록)
```

- **앱 이름**: `toss/app.mjs`의 `APP_NAME`을 앱인토스 콘솔에 등록한 appName과 똑같이 맞춰야 합니다.
- **설정**: `apps-in-toss.config.ts` (위쪽 바 투명, 당겨서 새로고침·튕김 끔, 권한 없음)

토스 안에서 달라지는 점:

| 항목 | 동작 |
|---|---|
| 화면 여백 | 토스가 알려 주는 값으로 위아래 여백을 잡고, 오른쪽 위 더보기·닫기 버튼 높이(44px)만큼 더 비웁니다 |
| 뒤로가기 | 한 단계씩 앞 화면으로 돌아가고, 첫 화면에서는 "게임을 종료할까요?"를 묻습니다 |
| 진동 | 토스 햅틱을 씁니다 (아이폰 포함) |
| 저장 | 설정·기록을 토스 저장소에도 보관해서, 다시 들어와도 남습니다 |
| 게임 로그인 | 시작할 때 사용자 식별값을 확인합니다 |
| 순위 | 완주 점수를 토스 게임센터 순위표에 올리고, "🏆 순위" 버튼으로 엽니다 (지원하는 토스 버전에서만 보임) |
| 화면 꺼짐 | 타는 동안 화면이 꺼지지 않습니다 |
| 공유 | 토스 공유 창으로 글과 토스에서 열리는 링크를 보냅니다 (바깥 사이트 링크 없음) |
| 지수 데이터 | 번들 안의 파일은 빌드 때 것이라, 매시간 갱신되는 사이트의 파일을 먼저 받아 옵니다 |
| 소리 | 켜기/끄기 버튼, 화면을 벗어나면 정지 (웹과 같음) |

실제 토스 앱(샌드박스)에서의 동작은 아직 확인하지 못했습니다. 출시 전에 샌드박스에서 꼭 확인할 것:
화면 위쪽 버튼과 겹침, 뒤로가기와 닫기(X) 버튼의 종료 확인, 순위표(콘솔에서 게임 정보 승인 필요), 소리.
